# Thermodynamique des trous noirs AdS révélée par la dynamique orbitale des particules

## 📖 Présentation

Ce dépôt rassemble l'ensemble des travaux scientifiques et numériques réalisés dans le cadre de mon **Projet de Fin d'Études (PFE) de Master** en **Physique des Hautes Énergies, Astrophysique et Sciences Spatiales (PHEA2S)** à l'**Université Cadi Ayyad de Marrakech**.

Ce travail porte sur l'étude de la **thermodynamique des trous noirs Anti-de Sitter (AdS)** à travers la dynamique orbitale des particules massives et des photons. Il reproduit et analyse plusieurs résultats de la littérature afin de mettre en évidence le lien entre les propriétés orbitales et les transitions de phase thermodynamiques.

Les simulations numériques ont été développées indépendamment sous **Wolfram Mathematica** et **Python**, permettant une validation croisée des résultats.

# 🔬 Objectifs scientifiques

Les principaux objectifs de ce travail sont :

- Étudier la thermodynamique des trous noirs AdS.
- Analyser les orbites circulaires des photons.
- Étudier l'ombre des trous noirs.
- Reproduire numériquement plusieurs résultats publiés dans la littérature scientifique.
- Mettre en évidence la relation entre la dynamique orbitale et les transitions de phase thermodynamiques.
- Comparer les implémentations numériques réalisées sous Mathematica et Python.

# 📑 Description des fichiers

## Thermodynamique_TN_AdS

Ce programme réalise les calculs numériques liés à :

- la température de Hawking ;
- l'énergie libre de Gibbs ;
- la capacité calorifique ;
- l'équation d'état ;
- les transitions de phase ;
- la construction de Maxwell (Equal Area Law).

---

## Orbites_Photons

Ce programme permet d'étudier :

- le potentiel effectif ;
- les orbites circulaires des photons ;
- le rayon de la sphère photonique ;
- le rayon critique ;
- le paramètre d'impact.

---

## Ombre_TN

Ce programme calcule :

- le rayon de l'ombre du trou noir ;
- les observables associées à l'ombre ;
- leur évolution en fonction des paramètres thermodynamiques.

# 📚 Bases théoriques

Ce travail s'appuie principalement sur :

- la Relativité Générale ;
- la thermodynamique des trous noirs ;
- la thermodynamique en espace des phases étendu ;

# 📈 Principaux résultats

Ce dépôt permet de reproduire plusieurs résultats importants de la littérature scientifique, notamment :

- les courbes de température de Hawking ;
- les diagrammes de l'énergie libre de Gibbs ;
- les courbes de capacité calorifique ;
- les diagrammes des transitions de phase ;
- l'étude des orbites des photons ;
- l'évolution de l'ombre des trous noirs.

Les résultats sont obtenus à partir de deux implémentations numériques indépendantes (Mathematica et Python), permettant une vérification de leur cohérence.
